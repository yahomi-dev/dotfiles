# 返答の言語 (強制)

- ユーザへの返答は必ず日本語で書く。英語で書き始めてしまったら、送る前に日本語に書き直す。
- 例外は、コード、コマンド、ファイルパス、識別子 (型名・関数名・ブランチ名など)、エラーメッセージやログの引用、固有名詞だけ。
- 入力やサブエージェントの結果が英語でも、報告は日本語で書く。英語のまま貼り付けず、要点を日本語にする (引用が要るときは短く)。
- MR / Issue / コミットメッセージ / レビューコメント / 貼り付け文も日本語で書く (識別子は除く)。
- 会話の圧縮 (compact) や /clear のあとも同じ。直前のやり取りが英語だったことは、英語で返す理由にならない。
