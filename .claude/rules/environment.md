# 作業環境の注意 (WSL と端末)

## 時刻

- 時間帯 (朝・夜・今日の後半など) に触れるときは、前景の Bash の `TZ=Asia/Tokyo date` か、ユーザの発言の時刻を使う。バックグラウンドの Bash の出力の時刻は UTC で出ることがあるので、経過時間の計算にだけ使う
- 記録 (状態ファイル、進捗のログ) と報告の時刻は JST で書く

## パスと貼り付け文

- ユーザの端末ではバックスラッシュが ￥ に見える。Windows 側のファイルは UNC (`\\wsl.localhost\...`) ではなく、`file://wsl.localhost/Ubuntu/...` のスラッシュ区切りの file URL で示す
- ユーザが別のセッションに貼り付ける文は `!` で始めない。Claude Code は `!` で始まる入力を bash モードで実行する。1 行目は「MR (!68) は〜」のように語から始める

## 一時ファイル

- scratchpad (`/tmp` 配下) は WSL の再起動で消える。残したいもの (下書き、計測のスクリプトと結果、MR 本文の案) は scratchpad に置かない

## worktree

- `EnterWorktree` で worktree に入ったセッションは、main の作業ツリーの側の git 管理外のファイル (状態ファイル、メモ) を編集できない。状態ファイルは worktree の直下に別に作成し、冒頭に「全体の正は main の側」と書く
- main の側で更新が要る項目は「worktree を出てからやること」にまとめておく。シェルで main の側へ書いて回避しない
- `ExitWorktree` は、ユーザが出ると言ったときだけ呼ぶ
