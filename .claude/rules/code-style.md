# コードスタイル共通ルール

## 基本方針
- 既存コードのスタイルを優先する（プロジェクトの .prettierrc, .eslintrc に従う）
- 修正箇所以外のフォーマットを変えない
- import の追加は既存の並び順に合わせる

## 命名
- 変数・関数: camelCase
- 型・クラス: PascalCase
- 定数: UPPER_SNAKE_CASE
- ファイル名: プロジェクトの既存パターンに合わせる

## コメント
- 修正したコードにだけコメントを追加する（既存コードにコメントを追加しない）
- 自明なコードにはコメント不要
- TODO を残す場合は理由を書く
