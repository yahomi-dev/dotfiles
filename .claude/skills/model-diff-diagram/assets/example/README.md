# 注文サービスのデータモデル図 (論理、架空の例)

model-diff-diagram スキルの実例。作業ディレクトリにコピーして、この README を書き換えて使う。

実体は日本語名、物理の表名は `<<...>>` の注記、属性は業務上の意味がある項目だけ (型・主キー・外部キーの列・on delete は書かない)。関係は動詞 (読む向き) と多重度 (1 / 0..1 / 0..* / 1..*)。

| ファイル | 内容 |
|---|---|
| 1-overview | 領域同士の関係 (flowchart。src/1-overview.mmd を直接書く) |
| 2-customers | 顧客: 顧客 / 住所 |
| 3-catalog | 商品: 商品 / 在庫 |
| 4-orders | 注文: 注文 / 注文明細 / 支払い |
| 5-all | 全実体を 1 枚に (属性あり) |
| 6-all-relations | 全実体を 1 枚に (関係だけ) |
| 7-legend | 凡例 (src/7-legend.mmd を直接書く) |
| 8-all-final | 全体の最終版 (色なし、削除したものなし) |

## 読み方

- 属性を書いた実体はその図で定義、注記だけの実体は別の図で定義 (関係を示すためだけに置く)
- 「属性名: 選択肢か補足」の行は、値が決まった選択肢から選ばれる属性 (状態、方法) か、属性の補足
- 色は 前回の版 (2026-01-10。コピーは baseline-2026-01-10.html) からの差分。緑 = 今回追加した実体・属性・関係、紫 = 名前や形を変更した実体・属性・関係、赤の破線と取り消し線 = 削除した実体・属性・関係 (図に残して見せる)

## 組み立てと描画

```sh
S=~/.claude/skills/model-diff-diagram
sh assemble.sh                                  # src/_*.part から 2〜6 と 8 の mmd を組み立てる
sh $S/scripts/render.sh . --png                 # SVG と確認用の PNG
node $S/scripts/build-html.mjs .                # data-model-diagrams.html
node $S/scripts/build-html.mjs . --artifact     # page.html
```
